## Project

DuHoc24, a "study-abroad application intake portal": the sample repo for a 6-week programming course. The current state is **Week 1: static UI only**. All data is hardcoded mock data in `lib/mock-data.ts`, and nothing calls an API or a database yet. The README's "Lộ trình tính năng theo tuần" section lists what later weeks add (Gemini chatbot, Supabase, document extraction, Make.com emails, Supabase magic-link auth). Don't build ahead of the week being worked on unless asked. All user-facing text is Vietnamese.

## Commands

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm run lint    # eslint (flat config, eslint-config-next)
```

There is no test suite. No env vars are needed yet; `.env.example` lists the Supabase and site-URL vars that later weeks will use (copy it to `.env.local`).

## Stack

- Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4 (configured in `app/globals.css`; there's no tailwind config file).
- shadcn/ui with the `base-nova` style, built on **Base UI** (`@base-ui/react`), not Radix, so component APIs differ from typical shadcn examples. Generated primitives live in `components/ui/`, and a `@tailark-oss` registry is configured in `components.json`.
- The `@/*` path alias maps to the repo root. Icons come from `lucide-react` and animations from `motion`.
- Next 16 global type helpers are in use (e.g. `LayoutProps<"/">` in `app/layout.tsx`).

## Architecture

- **Three surfaces:**
  - `/`: public landing page, composed from `components/landing/*` plus the shared `site-header` and `site-footer`.
  - `/portal`: student portal, composed from `components/portal/*`, showing `currentStudent`.
  - `/admin/*`: admin dashboard. `app/admin/layout.tsx` adds the sidebar, and `/admin` redirects to `/admin/requests`.
- **Data:** `lib/mock-data.ts` is the single data source and defines the domain types. Status and enum values are Vietnamese snake_case slugs (`DocStatus`: `chua_nop | dang_xu_ly | hop_le | can_nop_lai`; `RequestStatus`: `cho_duyet | da_duyet | tu_choi`; `ServicePackage`: `co_ban | toan_dien`). These types and collections are what get swapped for Supabase tables in later weeks (`requests`, `schools`, `conversations`/`messages`, `student_profiles`).
- **Status display:** `components/status-badge.tsx` holds the mapping from status slugs to Vietnamese labels and color tones (`docStatusMeta`, `requestStatusMeta`, `DocStatusBadge`, `RequestStatusBadge`). Add new statuses there, not inline in pages.
- Pages are server components. Only interactive pieces are client components (`quote-form`, `chat-widget`, `site-header`, `admin/sidebar`). The quote form and chat widget keep local state only and don't persist anything.
- `next.config.ts` allows remote images only from `images.unsplash.com`.
